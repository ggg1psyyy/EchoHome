# Architecture reference

EchoHome is built on [EchoMuse](https://github.com/wilbowes/EchoMuse) by Wil Bowes and the EchoMuse contributors. Its architecture reference, which covers the Echo's microphone array
and audio hardware in detail, is EchoMuse's:
[https://github.com/wilbowes/EchoMuse/blob/main/SETUP.md](https://github.com/wilbowes/EchoMuse/blob/main/SETUP.md).

EchoHome's own layout and rules are in [CLAUDE.md](CLAUDE.md), and the setup
steps in [docs/quickstart.md](docs/quickstart.md).
