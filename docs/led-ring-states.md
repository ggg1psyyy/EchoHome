# LED ring state model

EchoHome is built on [EchoMuse](https://github.com/wilbowes/EchoMuse) by Wil Bowes and the EchoMuse contributors. Its LED ring state model (owner priority, link availability, the button and audio event tables) describes EchoMuse, where the controller drove the
Echo's voice, and is EchoMuse's: [https://github.com/wilbowes/EchoMuse/blob/main/docs/led-ring-states.md](https://github.com/wilbowes/EchoMuse/blob/main/docs/led-ring-states.md).
In EchoHome the Echo is its own Voice Incubator satellite
([voice-incubator.md](voice-incubator.md)).
