# Audio state model

EchoHome is built on [EchoMuse](https://github.com/wilbowes/EchoMuse) by Wil Bowes and the EchoMuse contributors. Its audio state model (who owns the speaker, ducking, flush semantics) describes EchoMuse, where the controller drove the
Echo's voice, and is EchoMuse's: [https://github.com/wilbowes/EchoMuse/blob/main/docs/audio-states.md](https://github.com/wilbowes/EchoMuse/blob/main/docs/audio-states.md).
In EchoHome the Echo is its own Voice Incubator satellite
([voice-incubator.md](voice-incubator.md)).
