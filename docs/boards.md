# Boards

Which Echo hardware is supported, how the firmware finds each part by name
(`device/pkg/board`), and how to describe a new board are documented by
EchoMuse, whose board support EchoHome's firmware carries:
**[EchoMuse's board guide](https://github.com/wilbowes/EchoMuse/blob/main/docs/boards.md)**.

EchoHome is built on [EchoMuse](https://github.com/wilbowes/EchoMuse) by Wil Bowes and the EchoMuse contributors.
